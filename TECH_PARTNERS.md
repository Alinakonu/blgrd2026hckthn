# Tech partners

What to use for what.  
One card per tech partner, labeled by area of work. Click for technologies, use cases, and what you get.


Editor / host


Grok Bot

The host editor for this hackathon — build with Grok Bot (Cursor works too). Claim both $20 and $50 Cursor credit referrals when you check in.


Research / web data


Firecrawl

Give the app live web pages as clean markdown or JSON, not raw HTML.


Search / web


Exa

Neural web search so the agent finds sources — not just a URL you already have.


Design / UI


Wonder

Design on a canvas that is already production React + Tailwind — not a handoff mockup.


AI sandboxes


Daytona

Isolated computers that boot in milliseconds so agents can run code off your laptop.


Backend / state


Convex

TypeScript backend with a database and live updates — skip Postgres plus sockets for the demo.


Voice input


Wispr Flow

Dictate into Grok Bot — speech becomes clean text in the editor and chat.


Generate / media


Fal.ai

Run image, video, and audio models through one API so the demo can generate media.


API / models


x.ai

SpaceXAI / x.ai API — Voice, Chat, Imagine, and Grok Build via a Console API key (not Grok Bot).


Host / infra

Render

Ship a public URL from Git — web apps, static sites, databases, and workers.
