# Demo fixtures

Cached SoilGrids-style + Open-Meteo-style snapshots for three Vojvodina parcels.

**Why:** gods-eye-view keeps offline fixtures so demos survive flaky third-party APIs.
SoilShift does the same — set `USE_FIXTURES=1` or pass `useFixture=true` on `/api/analyze`.

These are illustrative point-in-time composites for hackathon demo reliability, not official soil survey products.
